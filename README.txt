SKILLBD FRONTEND
================

This is a standalone frontend demo built with:
- HTML
- CSS
- Vanilla JavaScript

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open index.html directly in Chrome/Edge.
3. No Node.js, npm, database, or server is required.

FEATURES INCLUDED
-----------------
- Responsive premium EdTech homepage
- Navigation
- Hero section
- Course listing
- Course category filters
- Course cards
- Category navigation
- Live class section
- Student success stories
- Learning dashboard preview
- Blog section
- Login modal
- Registration modal
- Free demo modal
- Toast notifications
- Mobile navigation
- Responsive desktop/tablet/mobile layout

IMPORTANT
---------
This is FRONTEND ONLY.
Login, registration, payment, course enrollment, video streaming,
admin dashboard, database, and API are currently UI/demo interactions.

Next phase can connect this frontend to:
